# 📊 Data Analyzer and Transformer

A menu-driven Python application that allows users to input, analyze, filter, and manipulate 1D and 2D arrays. This project demonstrates the use of Python fundamentals such as functions, recursion, lambda expressions, list comprehensions, filtering, sorting, and menu-driven programming.

---

## 🚀 Features

* 📥 Input data in **1D Array**
* 🧮 Input data in **2D Array**
* 📋 Display data summary

  * Total elements
  * Minimum value
  * Maximum value
  * Sum of elements
  * Average value
* 🔢 Calculate factorial using **recursion**
* 🔍 Filter data above a user-defined threshold using **lambda** and **filter()**
* ↕️ Sort 1D array in:

  * Ascending order
  * Descending order
* 📈 Display statistical information
* 🖥️ Interactive menu-driven interface
